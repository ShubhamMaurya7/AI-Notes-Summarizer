# 🧠 AI Notes Summarizer

An AI-powered web application that allows users to upload, type, or paste academic or professional notes, and receive concise, meaningful summaries using AI Model.

---

## 🚀 Features

- 📄 Upload PDF/Docs Notes
- 🤖 Summarize content using Google Gemini AI (Generative AI)
- 📌 Displays clean and concise bullet-point summaries
- 🧪 Simple Streamlit UI for interactive usage

---

## 🛠️ Tech Stack

- **Frontend/UI**: [Streamlit](https://streamlit.io/)
- **Backend**: Python 3.8+
- **AI Model**: Google Gemini
- **PDF Parsing**: [pdfplumber](https://github.com/jsvine/pdfplumber)
